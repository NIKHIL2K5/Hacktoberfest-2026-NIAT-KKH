# Pre-Event Prep — Hacktoberfest Hack Day

This is the quick checklist to go through before coming to the event.

You do **not** need to be an AI/ML expert. The goal is simply to revise the basics, understand the challenge categories, and make sure your laptop is ready so you can spend more time building during the Hack Day.

---

## 1. Revise Git & GitHub Basics

Be comfortable with:

```bash
git clone
git add
git commit
git push
git pull
```

Also revise:

- Creating a GitHub repository
- Branches and commits
- Public repositories
- Forking a public repo.
- Writing a basic `README.md`
- Adding an open-source license

Your final project must be published in a **public GitHub repository** with an **open-source license**.

Reference:
- GitHub Licensing: https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository
- Choose a License: https://choosealicense.com/

---

## 2. Revise One Programming Language

You should be comfortable with at least one:

- JavaScript / TypeScript
- Python

Use the language and stack you are already comfortable with.

You do **not** need to learn a new programming language just for the Hack Day.

---

## 3. Revise Basic API Concepts

Make sure you understand:

- What an API is
- GET and POST requests
- Sending and receiving JSON
- Calling an external API from your application
- Basic frontend-to-backend communication

---

## 4. Revise Basic AI Concepts

Have a basic understanding of:

- LLMs
- Prompts
- Context
- Tokens
- Open-source vs open-weight AI
- AI agents
- Tool calling

Good to know if you have extra time:

- RAG
- Embeddings
- Agent Skills
- Model harnesses

You only need a high-level understanding before the event.

---

# Challenge Categories

The two planned event challenges are listed in [PROBLEM_STATEMENTS.md](PROBLEM_STATEMENTS.md): Best Open-Source AI Project and Best Use of Gemma 4.

## Open-Source AI

For the MLH challenge, open-source or open-weight AI must be a central part of the project, which can be an application, an agent skill, or a model harness.

Revise:

- Open-source vs open-weight AI
- Agent Skills and model harnesses
- How to add an open-source license to a repository

References:
- Challenge brief: [challenges/open-source-ai.md](challenges/open-source-ai.md)
- Agent Skills: https://agentskills.io/

---

## Google Gemma

Gemma is Google's family of lightweight, open-weight models.

For the MLH challenge, participants can build with **Gemma 4 through the Gemini API**.

Revise:

- What an open-weight model is
- Basic prompt and API usage
- How an AI model can be integrated into an application

References:
- MLH Gemma Challenge: https://hacktoberfest-handbook.mlh.com/hack-days-partner-modules/partner-challenge-google-gemma
- Gemma Resources: https://mlh.link/gemma
- Gemma Quickstart: https://mlh.link/gemma-quickstart
- Gemma API Docs: https://mlh.link/gemma-docs
- Gemma Beginner Guide: https://mlh.link/gemma-beginnerguide

# What to Have Ready Before Coming

Please have:

- [ ] Laptop
- [ ] Laptop charger
- [ ] Git installed
- [ ] GitHub account ready
- [ ] Code editor installed
- [ ] Node.js or Python installed
- [ ] Working browser
- [ ] Basic Git/GitHub knowledge revised
- [ ] Basic API concepts revised
- [ ] Basic LLM concepts revised
- [ ] Basic understanding of open-source licensing
- [ ] Basic understanding of the two challenge categories

### Check your setup

For JavaScript / TypeScript:

```bash
node --version
npm --version
git --version
```

For Python:

```bash
python --version
pip --version
git --version
```

If these commands work, your basic development setup is ready.

# Important

Do **not** build your Hack Day submission before the event.

Before coming, focus on:

- Revising the basics
- Preparing your development environment
- Understanding the challenge categories
- Reading the relevant documentation
- Exploring small examples if you want

The actual project should be built during the Hack Day according to the event rules.
